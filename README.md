# 🚂 FAMILYMIRO CORE — Штабной Движок Решений для Строителя

**От PDF-чертежа и фото УПД на воротах склада — до печатных актов М-11 / М-15 / ТОРГ-2, АОСР, КС-2/КС-3 и выгрузки в 1С.**

## 1. История создания и 4 инженерных рубежа
1. **Рубеж 1 — Фоновый конвейер РД и контроль ревизий:** разбор томов `АР`, `КЖ`, `НВ`, `ГП`, `ЭС`, `ОВ`, `ВК`, аннуляция старых ревизий и сбор ведомости дефицита.
2. **Рубеж 2 — «Черепаха-Фреза» (ГОСТ 21.101 / 2.307):** вырезка узлов `М 1:20` с красной подсветкой, разворот шапок таблиц на 90°, CAD-схемы осей с размерными цепочками `6000 мм`, люки, проходки и трассы.
3. **Рубеж 3 — «Зрение сокола» и Шлюз 1С:** фото-приёмка УПД и сертификатов с контролем резкости и выгрузкой в **1С (`.xlsx` / `XML`)**.
4. **Рубеж 4 — Склад и юридические акты РФ:** приход `М-4`, выдача бригадам `М-11`, передача субподрядчику `М-15`, акты брака `ТОРГ-2`, списание в конструкцию `АОСР / М-29 / КС-2` и печать бланков А4.

## 2. Как пользоваться по ролям
- **Инженер ПТО:** загружает `PDF`-тома РД, использует Картотеку Узлов, CAD-схему осей и формирует АОСР.
- **Кладовщик / Снабжение:** принимает УПД по фото, оформляет `М-11`, `М-15` (субподряд) и `ТОРГ-2` (брак) с печатью А4.
- **Прораб / Бригадир:** открывает паспорт марки (`/marka/<slug>/`), смотрит узел `М 1:20` и считает запас и смены.
- **Бухгалтерия 1С:** выгружает реестры в **Excel (`.xlsx`)** и **CommerceML `XML`**.

## 3. Быстрый запуск на Windows (PowerShell)
```powershell
.\hello\Scripts\Activate.ps1
python manage.py migrate
python manage.py test storage_control --noinput
waitress-serve --listen=127.0.0.1:8080 --threads=8 --channel-timeout=120 core.wsgi:application
```
Откройте в браузере: **`http://127.0.0`**

## 4. Ключевые модули системы
- `storage_control/services/pdf_ocr.py` — разбор PDF-томов РД (`pypdfium2` + `pypdf` + `pdfplumber`).
- `storage_control/services/turtle_geometry.py` — «Черепаха-Фреза»: вырезка узлов `М 1:20`, разворот шапок 90°, трассы, оси ГОСТ 21.101, люки и проходки.
- `storage_control/services/falcon_vision.py` — «Зрение сокола»: приёмка фото УПД и выгрузка в 1С (`.xlsx` / `XML`).
- `storage_control/services/stock_acts.py` — движение ТМЦ (`М-4`, `М-11`, `М-15`, `ТОРГ-2`, `АОСР`) и печатные бланки А4.
- `storage_control/services/mark_passport.py` — инженерный паспорт марки, аналоги и калькулятор смен.
